## JobFinder v1.0.0

* **Android APK (Direct Install)**: `JobFinder-v1.0.0.apk`
* **Universal Android APK**: `jobfinder.apk`
* **Desktop / Web Application**: `index.html` (PWA Offline Ready)

### ✨ Features & Improvements in v1.0.0

* 📱 **Dedicated Native Mobile UX**: Built specifically for Android touch displays with centered header, bottom glassmorphic navigation dock, and zero-overflow layout.
* 🔍 **Unified Luxury Job Search Engine**: Parallel aggregator across LinkedIn, Naukri, Indeed, Glassdoor, and ZipRecruiter with real-time scan progress bars.
* 🤖 **Intelligent AI Chat Copilot**: Drag-and-drop resume tailoring with multi-provider AI support (Google Gemini, OpenRouter, NVIDIA NIM, Groq, DeepSeek).
* 📄 **Jake's ATS Resume Generator**: Real-time ATS single-column resume with interactive in-browser LaTeX (`.tex`) code editor and instant PDF export.
* 📋 **Application Pipeline Tracker**: Kanban and list views with follow-up notifications, Notion database synchronization, and CSV export.
* 🛡️ **Defensive Security Hardening**: OWASP Top 10 compliance with LaTeX syntax injection escaping, strict schema sanitization, and reverse tabnabbing protection.
* 💾 **Full Offline Persistence**: Zero-cloud-dependency local database powered by Dexie.js (IndexedDB) with backup export & import.
